🚀 Запуск демо системы

Нажми кнопку ниже или скопируй команду для запуска в терминале:

Или скопируй команду в терминал:

curl -X POST -H "Accept: application/vnd.github.v3+json"  https://api.github.com/repos/Artyom743/demo_ui/actions/workflows/demo_pub1.yaml/dispatches -d '{"ref":"main"}'

Результаты появятся в разделе Actions → Artifacts через несколько минут
